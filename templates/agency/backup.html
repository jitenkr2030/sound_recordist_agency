SYSTEM ADMINISTRATION

Backup & restore

Create a downloadable ZIP backup of the SQLite database and uploaded media. For PostgreSQL, use pg_dump/pg_restore as described in the README.

Download backup ZIP
Restore guidance
  1. Stop the Django server.
  2. Extract the backup ZIP in a secure working directory.
  3. Replace the SQLite database and restore the media folder.
  4. Run migrations and verify records before reopening access.
Restore is deliberately a manual administrator procedure to prevent accidental overwrite of live business data.
